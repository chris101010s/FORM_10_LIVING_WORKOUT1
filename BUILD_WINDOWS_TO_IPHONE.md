# FORM 10.0 — Windows → GitHub → iPhone

1. Falls du bestehende FORM-8.4-Daten behalten möchtest: zuerst JSON-Backup aus der App exportieren. Gleiches Repository und dieselbe Apple-ID/Signierung verwenden. Nicht deinstallieren, wenn du deine Daten behalten willst. Die neue Version verwendet denselben 8.4-Speicher. Neue Installationen sind leer.
2. ZIP entpacken. Den **Inhalt** (inklusive `.github`, `modules` und `.gitignore`) in den bestehenden Repository-Hauptordner kopieren, nicht als zusätzlichen Unterordner. Vor dem Ersetzen eine Kopie der vorherigen Dateien erstellen. Prüfe die Änderungsübersicht in GitHub Desktop. Falls aus einer älteren Version `modules/athlete-ocr` noch vorhanden ist, entfernen; `modules/form-health` behalten.
3. Falls eine alte `package-lock.json` existiert, `npm install` mit Node 22.16 oder einer geeigneten neueren Version ausführen, damit die neue Versionsnummer synchron ist. Lockfile committen, falls vorhanden. Ohne Lockfile verwendet die Pipeline `npm install`. Keine persönlichen Daten oder Backups committen.
4. Commit `FORM 10.0 Living Workout` erstellen und pushen. Actions → **FORM 10.0 – iOS IPA (unsigned)** → neuen Run öffnen. Alternativ Workflow manuell auslösen. Der bisherige `custom_tabs`-Schalter ist weiterhin verfügbar. Der Runner `xcode-27` wurde aus der bestehenden Pipeline übernommen; tatsächliche Verfügbarkeit und Xcode-Build müssen auf GitHub bestätigt werden. Mac-Runner verbrauchen GitHub-Actions-Kontingent.
5. Erst wenn alle Schritte einschließlich CocoaPods und Xcode erfolgreich sind, IPA unter Artifacts herunterladen, entpacken und mit Sideloadly installieren. Bei Fehler den ersten roten Schritt samt vollständigem Log prüfen. Das CI-Testprotokoll und Crypto-/Xcode-Logs werden im Fehlerfall bereitgestellt. Standardmäßig werden HealthKit- und Widget-Entitlements nicht aktiviert.
6. Auf dem iPhone den Geräte-Testplan in `RELEASE_REPORT.md` abarbeiten. Optional kann bei leerer Neuinstallation die Einrichtung übersprungen werden. Sideloadly-Builds müssen abhängig von der Signierung regelmäßig erneuert werden.
